# 🏋️ Fitness Club Member Analytics Dashboard | Power BI

## 📌 Project Overview

The **Fitness Club Member Analytics Dashboard** is an interactive Business Intelligence solution built using **Microsoft Power BI** to analyze member demographics, activity patterns, trainer allocation, and fitness engagement metrics.

The objective of this project is to transform raw fitness club data into meaningful business insights through data cleaning, modeling, DAX calculations, and interactive visualizations, enabling data-driven decision making.

---

## 🎯 Business Problem

Fitness clubs generate large amounts of member data every day, but extracting actionable insights from raw datasets is challenging.

This dashboard helps answer important business questions such as:

- How active are club members?
- Which membership plan is most popular?
- How are members distributed across trainers?
- What is the relationship between daily steps and calories burned?
- How does emotional well-being vary among members?
- What demographic patterns exist within the club?
